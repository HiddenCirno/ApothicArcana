# ApothicArcana / 神化：奥术秘法

面向 **Minecraft 1.20.1 / Forge 47.x** 的 Apotheosis 附属模组。

- **奥术附魔台**：保留原版式附魔台与随机三选一，但可以在书架允许的范围内自由调节
  位阶、量子化与阿卡那。
- **终极奥术附魔台**（需要 Enchanting Infuser）：逐条魔咒自由选择与改级，
  并支持神化的灌注配方。
- **极限重铸台**：可重铸至远古稀有度。
- 珍宝材料递进合成链、创造模式镶孔符石等。

## 依赖

| 类型 | 模组 |
|---|---|
| 必需 | Apotheosis 7.4.8+、Placebo 8.6.2+、Apothic Attributes 1.3.5+ |
| 可选 | Enchanting Infuser 8.0.3–8.0.x（仅终极奥术附魔台需要） |
